# IntegrityLens frontend

This folder contains the React, TypeScript, and Vite application, its browser worker, public assets, and fictional demo corpus.

Run it from the repository root:

```sh
npm run dev
```

For Supabase mode, copy `.env.example` to `.env.local` in this folder and set the public Supabase URL, anonymous key, and assignment ID. Never place a service-role key in frontend environment variables.
